Had to rewrite this from scratch to support a wider range of blender versions.
This is now targeting versions 4.0-4.3. Support for 3.6 is discontinued.

Before using this, make sure you click the "Install Dependencies" button.

After that restart Blender.

To install, copy the umvc3_model_importer folder in your Blender plugins folder OR turn into a zip and install it through the Preferences window under the Edit tab.
This version incorporates the model importer and exporter into the UI.

Some features are still incomplete.
